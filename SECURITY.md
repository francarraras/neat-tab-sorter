# Security policy

Please report security problems privately, not in public issues: on the repository's **Security** tab, choose **Report a vulnerability**. You'll get a reply as soon as possible.

Only the latest version gets fixes. Neat Tab Sorter has no server and makes no network requests, so the main things to look at are its permissions (`tabs`, `tabGroups`, `storage` and `contextMenus`) and the code that runs in the browser.
